Linda: referência rápida

Espaço de tuplas e casamento de padrões (09b-Linda.pdf, "s.N" = slide). Lição completa: Lição 8.

Em uma frase. Ninguém manda mensagem para ninguém: os processos põem tuplas num espaço de tuplas (TS) compartilhado e tiram as que casam com um padrão (s.2–3). Na questão 5 de 2026: assíncronas: sim (independência de tempo e da existência dos processos, s.2, 7) · síncronas, rendezvous, monitores: não.

Os exemplos dos slides

Exemplo 1 (s.4)

Output(1, 'A');
Input(I: Integer; C: Character);     -- pega (1,'A'): I = 1, C = 'A'

Exemplo 2: pedidos de trabalho (s.5)

Input("job", J: Job_ID; 24)       -- proc 24 espera para servir
Output("job", 17, 24)             -- envia pedido ao proc 24
Output("job", 17, P: Process_ID)  -- envia pedido a qualquer processo

A string identifica o pedido, o inteiro identifica a tarefa, o nome identifica o ID do processo.

RPC só com tuplas (s.6)

Cliente:   Output("Proc", 24, 65, 'X');           -- procedimento, quem chama, 2 parâmetros
           Input(24, B: Boolean);                 -- espera a resposta com o seu ID
Servidor:  Input("Proc", Caller: Process_ID; I: Integer; C: Character);
           Proc(I, C, B);
           Output(Caller, B);                     -- devolve para quem chamou

O truque: o cliente põe o próprio ID na tupla, e a resposta volta marcada com ele.

Multiplicação de matrizes (s.8–10)

-- cliente: põe linhas de A, colunas de B e o contador; depois recolhe os 9 resultados
Output('A', 1, (1,2,3));  …  Output('B', 3, (1,1,1));
Output("Next", 1);
for I in 1..3 loop for J in 1..3 loop
  Input('C', I, J: Integer; C: Integer);
end loop; end loop;

-- cada worker (quantos quiser)
loop
  Input("Next", Element);           -- tira o contador: ninguém mais pega o mesmo job
  Output("Next", Element + 1);      -- devolve o próximo
  exit when Element > 3*3;
  I := (Element - 1) / 3 + 1;       -- job → linha
  J := (Element - 1) mod 3 + 1;     -- job → coluna
  Row_Tuple := Read('A', I, V1);    -- Read: a linha continua lá para outros jobs
  Col_Tuple := Read('B', J, V2);
  X := Inner_Product(V1, V2);
  Output('C', I, J, X);
end loop;

O contador "Next" é exclusão mútua feita com uma tupla: enquanto um worker está com ela, os outros suspendem no Input. Os números da matriz no slide 8 têm erros (linha 1, coluna 3 deveria ser 6) e as colunas postas em s.9 não batem com a matriz; o algoritmo não muda.

O código está escrito com a notação de Ada: :=, --, mod, for … in 1..3 loop, exit when (sai do laço quando a condição vale). Veja a referência de Ada.
