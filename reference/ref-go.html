Os três pilares e os diferenciais

  • Goroutines: threads de nível de usuário, extremamente leves, gerenciadas pela runtime (s.2).
  • Channels (CSP): processos não compartilham memória para se comunicar (s.3).
  • Scheduler M:N: M goroutines em N threads do sistema operacional, usando bem vários núcleos (s.4).
  • Diferenciais: simplicidade (basta go, sem locks e semáforos), segurança (channels como pipelines evitam race conditions), eficiência (milhares de goroutines) (s.4–6).

Exemplo Ada × Go (08 s.26)

func main() {
    getData := make(chan int)     // canal é o ponto de rendezvous
    go func() {                   // equivalente à task Server
        getData <- 42             // equivalente ao Accept
    }()
    data := <-getData             // cliente bloqueia até servidor enviar
    fmt.Println(data)
}
